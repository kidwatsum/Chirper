# 🐦 Chirper

A minimalist, high-performance Twitter/X clone built with **Laravel** and styled with clean, animated components of **Magic UI** (via Tailwind CSS).

Chirper allows users to create accounts, authenticate securely, and share short thoughts ("chirps") in real-time, featuring full CRUD capabilities for their own posts.

## ✨ Features

- **Secure Authentication:** Complete Login and Registration system powered by Laravel.
- **The Chirp Feed:** A dynamic main dashboard where you can view all public chirps.
- **Full CRUD Control:** Create new chirps, and completely edit or delete the chirps _you_ own.
- **Modern UI/UX:** Elevated with smooth, animated components and sleek layouts courtesy of Magic UI and Tailwind CSS.
- **Authorization Guards:** Strict server-side validation ensures users can only modify or delete their own content.

---

## 🛠️ Tech Stack

- **Backend:** Laravel 11 (PHP)
- **Frontend:** Blade + Tailwind CSS
- **UI Components:** Magic UI
- **Database:** SQLite
